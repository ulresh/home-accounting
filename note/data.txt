последние null в строке не записывать.

cost можно с копейками, но чаще без.

При смене версии приложения header может быть записан новый.

Записи группируем в файл по значению "<event_datetime>".
В одном файле записи за месяц.
Месячные файлы складываем в отдельные папки на каждые 10 лет.

RN - добавочный номер для случая, когда несколько записей добавлены
на одному стройстве в одну секунду, обычно RN=0.

event-datetime в delete добавлен для поиска при синхронизации,
а в update для информации, если новое значение в другом файле.

Файлы событий не удаляем, не перезаписываем и не исправляем.
Только дозапись в конец файла.


Синхронизация.
По команде пользователя из интерфейса.
По возможности сохранить порядковые номера новых устройств при передаче.
Результат - передано N записей, принято K записей.
Устройства в одной локальной сети.
JSONL over TLS.
Случайный свободный порт.
Desktop - телефон, телефон - телефон, - IP, порт,
код подключения (случайная буквочисленная последовательность длиной 8)
передаются через QR+камера телефона.
Desktop - Desktop скопировать или ввести вручную.
Для нового устройства запросить подтверждение, известные устройства
синхронизировать сразу.
При синхронизации проверять совпадение имени текущей базы данных,
при несовпадении предлагать переключиться или создать новую и переключиться.
